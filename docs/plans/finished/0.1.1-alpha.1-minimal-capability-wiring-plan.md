# 0. 目标

本版本只交付：

1. 不同 teammate 获得不同 **Team tools**；
2. 不同 teammate 获得不同 **Team-managed skills**；
3. 不同 teammate 获得不同 **Team MCP**；
4. 不同 teammate 可以对 **DSH/base preset 继承的 built-in tools 设置 deny blacklist**；
5. create / cold resume / dispose 后上述能力仍正确；
6. legacy Blueprint 不回归；
7. `CORE PATCH BUDGET = 0`。

不交付：

```text
parameter permission
path rule
ask
allow_once
grant_instance
dynamic permission mutation
teamHardDeny
Human hard override
permission admin UI
async approval
```

# 3. 语义边界

## 3.1 Team tools

只管理：

```text
createTeamTools()
```

产生的 Team tool catalog。

```text
allow(items)
→ 只注册 catalog 中 name ∈ items 的 Team tools

deny
→ 注册 0 个 Team tools
```

unknown item：

```text
不 materialize
记录 diagnostic 即可
```

不要因此建立 compatibility engine。

---

## 3.2 Built-in tool deny

`builtinToolDeny` 管理：

> Agent 从 base preset / DSH /其他正常继承路径获得的 tool visibility。

实现：

```text
agent.ctx.tools.restrict({ deny: builtinToolDeny })
```

要求：

- Agent scoped；
- sibling 不受影响；
- cold resume 后重新生效；
- dispose 后 scope effect 消失；
- 不修改 global registry。

### 注意

这是 blacklist，不是完整 sandbox。

如果一个允许的 MCP 自己暴露 shell/filesystem 等能力：

> MCP 必须通过 `mcp` policy 另行关闭。

alpha.1 不承诺 capability effect analysis。

---

## 3.3 Skills

只控制 Team-managed skill catalog。

```text
allow(items)
→ 注册允许的 Team skill definitions

deny
→ 注册 0 个 Team-managed skills
```

不隐藏 DSH/global inherited skills。

---

## 3.4 MCP

只控制 Team-managed/configured MCP。

最低实现：

```text
当前 configured server = X

allow(items contains X)
→ mount X

allow(items excludes X)
→ no mount

deny
→ no mount
```

如果 production 已自然支持多个 server：

```text
逐 server filter
```

否则不扩展 catalog。

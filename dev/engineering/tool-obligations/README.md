# dev/engineering/tool-obligations — the tracked ExpectedToolObligations artifact (U7-0 / EB2-A)

This directory is the REVIEWED, TRACKED home of the tool-obligations
artifact family the dynamic tool census reconciles against
(execution-plan U7 / EB2-A; architecture §10.4; U4 seed law). Before U7-0
the reviewed obligation set lived only inside untracked evidence; the
verification target "a fixed snapshot digest + expected↔observed↔sources
reconcile" requires the EXPECTED side to be a reviewed tracked input, and
this is where it lives.

## The law of this directory

1. **The artifacts are a PROJECTION, never hand-edited.**
   `expected-tool-obligations.v1.json` and
   `authoritative-tool-sources.v1.json` are generated by
   `build-expected-tool-obligations.mjs` from three TRACKED reviewed
   inputs, and CI replays the generator byte-identically
   (`node build-expected-tool-obligations.mjs --check`; the C1 hook
   `packages/testkit/test/u7-0-census-reconcile.test.ts` runs it).
   Editing an artifact without changing its inputs is impossible;
   changing an input without re-generation fails the replay.
2. **The reviewed inputs are the authority.** `sources/` carries the
   U4-reviewed obligations seed (91 entries, 58 REQUIRED / 33 OUT_OF_SCOPE,
   the review pinned by the U4 artifacts it cites), the U4
   unknown-dispositions seed, and the merged u1c static source census
   (75 host + 21 team registration rows + the dynamic source classes).
   The generator cross-checks every REQUIRED name against the tracked
   matrix/backlog markdown and REFUSES to emit an unclassified entry —
   fail-closed, never a silent default.
3. **Digests are recorded.** `manifest.json` pins the sha256 of every
   artifact, both schemas, the generator itself, and each reviewed input.
   The runtime loader (`packages/testkit/census/expected-obligations.mjs`)
   re-validates every artifact against its tracked closed schema before
   any consumer sees it (malformed → throw, never a partial load).
4. **Scope classification is reviewed, not guessed.** Where the U4 seed
   left scope open (sibling-tool variants, opt-in rows), the generator's
   SCOPE_RULES / SCOPE_SAME_AS / SCOPE_OVERRIDES tables are an explicit
   reviewed mapping (each carries its `why`); anything unmatchable is a
   generation-time refusal.
5. **Baseline snapshots** (`baselines/`) are pinned C2 live observations:
   the recorded `snapshot_digest` covers ONLY cross-boot-stable facts
   (per `packages/testkit/census/inventory.mjs` digest law) — placement
   identities (`def#N`) and registration generations are per-boot and are
   recorded but NEVER digest-compared across boots; model-facing shape
   digests are.

## Files

| file | role |
| --- | --- |
| `build-expected-tool-obligations.mjs` | deterministic generator (no timestamps, canonical key order; `--check` replay mode) |
| `expected-tool-obligations.v1.json` | the reviewed obligation set (91 named/dynamic-class/surface entries) |
| `authoritative-tool-sources.v1.json` | static registration census + dynamic source classes |
| `expected-tool-obligations.schema.json`, `authoritative-tool-sources.schema.json`, `../packages/testkit/census/observed-runtime-inventory.schema.json` | closed schemas (validated through the closed-keyword checker) |
| `sources/*.seed.json` | reviewed tracked inputs (U4 + u1c), sha-pinned in the manifest |
| `manifest.json` | digest ledger (artifacts + schemas + generator + inputs) |
| `baselines/` | pinned live C2 snapshots (one per world class) + their RUN receipts |

Note: the generator and the census library are plain `.mjs` files run
from source (test/diagnostic code — NOT product, NOT shipped through any
dist; the census probe row registers ONE tool on a TEST profile and never
changes product behavior).

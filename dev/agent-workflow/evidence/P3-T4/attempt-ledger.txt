## Design change in-cycle: contracts-mirror decoupling

Root-cause investigation (read-only) for D1/D2:
- `packages/domain/tsconfig.json` (NOT owned by P3-T4): extends tsconfig.build.json, `noEmit: true`, `rootDir: "."`, include `["src","test","vitest.config.ts"]` → TS6059 forbids ANY non-declaration source file outside `packages/domain` in the program.
- `packages/contracts/package.json`: `main`/`exports`/`types` all point at `dist/**`; **dist is not built** (no build step in the canonical chain) and `@dsh-agent-team/domain` declares NO dependency on contracts → the bare specifier `@dsh-agent-team/contracts` resolves to nothing (checked `packages/contracts/dist` — absent; no other package in the repo imports contracts yet, so no established pattern exists).
- `scripts/run-tests-hooks.mjs`: only rewrites the `vitest` bare specifier and RELATIVE `.js`→`.ts` siblings; bare package specifiers are left to stock Node resolution.
- Conclusion: within P3-T4 owned paths (`packages/domain/policy/**` + `packages/domain/test/t4-*.test.ts`), the only way to keep BOTH typechecks green is to keep relative imports for runtime (the hook rewrites them) while keeping contracts `.ts` sources OUT of the tsc program → the package cannot import contracts at all.

Fix (all inside owned paths): new `packages/domain/policy/src/contracts-mirror.ts` — a faithful local mirror of exactly the contracts-v1 surface the resolver consumes (session/instance id rules incl. `inst-[a-z0-9]{1,32}`, `TeamSessionId = RootSessionId` invariant 9, `MemberIdentity` composite + `LEADER_INSTANCE_ID` + `createMemberIdentity` (deep-frozen) + `assertMemberIdentityInTeam` invariant-18 guard, `deepFreeze` lossless-JSON assert + freeze). Two documented deltas: compile-time-only brands erased to plain `string` aliases (real branded values stay assignable); boundary violations throw the policy's own `PolicyResolutionError` (malformed ids → `MALFORMED_POLICY_INPUT`; cross-scope identity → `IDENTITY_SCOPE_MISMATCH`, keeping the contracts-v1 code string; the code was added to the closed `POLICY_ERROR_CODES` set). All 6 import sites rewired (3 src + 3 tests); the 3 identity-boundary negative tests rewritten to assert the policy error type with the preserved code string and exact `details`. When the repo build wiring makes contracts resolvable (built dist + declared dep), the mirror can be retired for the real import (module doc says so).

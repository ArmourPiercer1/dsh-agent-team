## 披露（如实）

- **bytes-正向（A 读到自己作业字节）装面格 = 不可构造**（J8 三臂法），不是未测；单元面同路已绿。
- corded:true（Team 已归属作业）装面格 = 无公开归属注入面（生产桥无归属生产者；kit 无法达 glue 装配实例——`liveJobsGatewayFor` 在 bindings 面上，kit 非在程消费者）。登记为 B-ACT-2 候选（如需装面 corded 格，需一个公开 witness/归属缝——当前无，且造它=新面需单独批准）。
- 桥文本=自组披露偏差（renderModelDelta 非导出），正/拒面文本形态与宿主原生不同名同义=在册法。

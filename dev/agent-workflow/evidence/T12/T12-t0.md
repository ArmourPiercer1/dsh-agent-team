### SP4 (transport caller identity) — VERDICT: AMBIGUOUS (subagent 96b11823)
- Connection edge: browser reaches host via (a) unary RPC POST /api/<endpoint> with `{type:'client-request', rpcId, method, payload}`, gated by per-DSH_HOME HMAC-signed cookie `dsh-auth-<sha256(authority)>` (secret durably stored in DSH_HOME credentials `client-connection/browser-session`) + loopback/Host fence + same-origin check; 401/403 BEFORE dispatch; (b) WebSocket /api/remote.mux gated by the same fence, wire carries no identity; (c) index page auth-gated via launch-token exchange. Host binds 127.0.0.1 only (`--host 0.0.0.0` rejected at startup).
- Trust model: SINGLE ANONYMOUS OPERATOR per DSH_HOME. No user accounts, no per-browser/tab id, no subject in cookie. Fence "is not an auth layer"; auth = cookie check. Host trusts cookie-valid caller as the operator of this DSH_HOME; it merely RECEIVES (never verifies) payload claims (sessionId, actor/caller).
- Plugin handler boundary: ZERO caller fields. Public seams: (i) `ctx.connection.rpc.handle(channel, handler)` / `rpc.intercept('/api', matcher, handler)` — handler `(endpoint, payload, signal) => ConnectionRpcResult` (rpc-host.ts:77-93, rpc.ts:127-131); (ii) `ctx.connection.fetch.register({path, methods, fetch(request)})` — full Fetch Request (headers readable); (iii) raw `ctx.webServer.register(...)` — must self-apply `ctx.connection.requestRejection(req)`; (iv) Typert Gateway services — wire args only.
- CONSEQUENCE for T12: B4 fail-closed is the only honest design; the transport contribution to PrincipalContext is the all-or-nothing "authenticated operator of this DSH_HOME" established UPSTREAM of dispatch (any request reaching a seam-mounted handler has passed the 401/403 gate). Finer authority (team scope, bound root, actor kind) stays derived from host-owned durable/bound facts = existing A32 (s6-principal). A browser CANNOT self-claim authentication (HMAC secret host-owned) but CAN self-claim which session/agent/actor it operates on.
- M4 relevance: `ctx.connection.rpc.handle(channel, handler)` is a candidate PUBLIC browser-facing mount seam (SP3 to confirm semantics).

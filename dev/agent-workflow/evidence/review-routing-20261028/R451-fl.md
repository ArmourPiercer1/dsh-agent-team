### (2) Mask widening cannot cause false drift — PASS
`modeOf` widened to `& 0o7777` (lib :159). It is used in exactly three places:
- :416–417 present-path compare `actualMode !== f.modeBits` (ASSET_MODE_DRIFT),
- :486–487 post-copy re-read compare `publishedMode !== f.modeBits` (PUBLISHED_MODE_MISMATCH),
- :160 `modeString` — re-masks `& 0o777`, so the classic 3-digit display/record format is unchanged (T24's `f.mode === '0o755'` still passes).

`f.modeBits` comes from `parseManifestMode` gated by `MANIFEST_MODE_RE = /^0o[0-7]{3}$/` (lib :165–175), so every pin is ≤ 0o777 and never carries a special bit. For a file with no special bits, `mode & 0o7777 === mode & 0o777` → comparison identical to before. **No behavior change for normal 0o600/0o644/0o755 pins.** Empirically: ran the full suite in my own detached worktree at head — **26/26 pass** (`node --test tests/world-factory/host-sandbox-assets.test.mjs`, 4.9 s), including all 24 pre-existing tests.

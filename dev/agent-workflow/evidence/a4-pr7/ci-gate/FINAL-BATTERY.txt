WHAT THE GATE WILL NOT MEASURE (design rules, in the script header) -----------
  1. lint and the fence grade IDENTITY DIFFS, never exit codes (both are red at
     base by standing debt; an exit code there is noise).
  2. the census grades an IDENTITY SET, never counts.
  3. an ESCALATION is a failure even though the red count dropped.
  4. a missing DSH-CI-VERDICT token is FAIL, never "not run" — and the token is
     printed from a `finally`, so a harness throw still produces one.
  5. a skip is NAMED (verdict=skip … skipped=census) and under --full any skip is
     a failure. There is no silent skip anywhere in this gate.
  6. tolerance authority is the BASELINE DOCUMENT, not this script: flaky families
     are parsed out of the baseline's prose (parseLoadFamilies). F6 below.
  7. the census leg states its CLOCK, so a pass says what it passed under.

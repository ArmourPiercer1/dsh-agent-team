WHAT WOULD ACTUALLY BREAK, and what it would mean
  - Step 2 without `--store-dir`, or without the XDG exports: pnpm reaches for `$HOME`
    and the run dies inside the installer. Not a code failure; re-run with the prefix.
  - Step 8 printing the client line as PASS: the closure became resolvable; the gate is
    now checking MORE, and the SKIP disappears honestly.
  - Step 8 exiting 0 while printing NO line for the client step: the three-state
    classifier regressed into a mute. That is the failure mode this whole task exists to
    prevent; treat it as a blocker, not a flake.
  - Step 7 exiting non-zero after step 6: the committed install-surface mirror moved.
    Rebuild and co-commit; never widen or silence the check.
  - Step 9/12 failing to create `packages/testkit/test/.tmp-fault/`: sandbox artifact,
    report it as such with the exact errno.

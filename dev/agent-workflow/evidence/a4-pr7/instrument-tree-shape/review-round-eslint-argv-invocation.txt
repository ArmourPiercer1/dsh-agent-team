### DISCLOSES the paths it skipped rather than dropping them silently.

lintable tracked paths (`git ls-files`, code extensions): 2418; on disk: 2417;

So: `npx` never starts eslint on an argv of this size (exit 249, nothing written, ~0.2 s;
the only thing it prints is the npm config warning), and the bin refuses the whole batch
(exit 2, empty stdout) if ONE path in it is not a file — an error class that has nothing
to do with the code under review and would surface as `NOT RUN`. Filtering to existing
paths is what makes the census runnable; disclosing the one filtered path is what keeps
the census honest about its own denominator.

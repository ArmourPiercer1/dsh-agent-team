## Findings (non-blocking)
- **F1 (observation, residual risk accepted by the law itself)**: a real marker typed in mixed/lower case (`Do-Not-Merge`) on body line 1 is prose per §8.5.6.1 (大小写敏感) — if such a PR also carries a genuine settlement, the gate PASSes. Mitigants: without a settlement the verdict is still FAIL (never green by accident); a settlement is itself a human-issued authority (§8.5.2), so the scenario requires a human to settle a PR they simultaneously marked down; §8.5.6.1 additionally mandates fullwidth/bracketed forms for prose mentions. Law, not bug — noted so future amendments can revisit case-folding if real-world near-misses occur. (`pr-settlement-gate.mjs:68`, self-test case "lowercase is not the canonical token".)
- **F2 (nit)**: `LOOSE_SETTLEMENT_RE` (gate.mjs:80) treats any first line containing both words "dated" and "settlement" as a diagnostic candidate — harmless (candidates can never flip a verdict; verified by battery j) and it is explicitly labeled diagnostic-only.
- **W1 (wording nit)**: §8.5.6.6's lead 「§8.5.1–8.5.5 由本项起为机器判定」 slightly overstates scope read in isolation (the machine decides form+sha, not §8.5.2's four-element substance); immediately corrected by §8.5.6.2 ("可执行化，不改变其语义") and §8.5.6.3's explicit merge-agent split, so it does not actually over-claim in context. Optional tightening in a future dated amendment; not worth a fix round here.

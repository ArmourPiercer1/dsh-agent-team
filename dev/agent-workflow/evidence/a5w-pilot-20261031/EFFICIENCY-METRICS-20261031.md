## §1 口径（先钉死后落数）

- **四段** = ①实现段 = PR 首 commit（authoredDate）→ PR 创建（READY）；②审查段 = PR 创建 → **首条在案审查记录回报**（= 承载审查 verdict 的 dated 清偿评论 created_at；审查席**启动**时刻在 12 样本均无独立在册 → 启动记 UNPROVEN，审查段为「创建→回报」上界，含排队）；③清结算段 = 审查回报 → mergedAt（含 fmerge+全绿门排队）；④总 = PR 创建 → mergedAt。
- **审查记录在案判据**：清偿评论正文含 verdict（PASS/SUPPLEMENT/BLOCK 语义）或明写「reviewed content … unchanged」；仅「review seat to follow」的预清偿**不**算回报。#511/#512/#492/#495/#496 无承载 verdict 的评论 → 该两段 UNPROVEN（sync16 L7327 仅汇总「全部独立审查」无时刻）。
- **CI 轮** = 该 PR head 上 distinct head_sha × 4 条 workflow（pr-gate / ci-required / census-runtime / candidate-protection）；**无效重复** 分两类计数：(a) **纯 fmerge 轮**（head 仅前进合并 master、内容零变化）触发的全套重跑；(b) **rerun**（同 run_number 的 attempt>1，即 `gh run rerun --failed`）。真红轮（修复驱动）不算无效。

## §5 教训量化（估算显式标注）

1. **leaf-first/波次后行队列序**：实测纯 fmerge 轮 10 轮 ≈205 分钟 ci-required runner 墙钟（§3）。归因：#512/#514/#515 三根叶子的 3 轮 + #516 波次 PR 的 2 轮 = 5 轮（≈104 分钟，ci-required 实测 20.4+21.1+20.5+18.9+26.5）源自「叶子未先合、波次 PR 先开」的重叠在途；**估算**（标注=估算，非实测）：严格执行「依赖就绪才开 PR、叶子先合、波次 PR 最后开」可省 5–10 轮（≈104–205 分钟）；剩余轮次是 strict 保护下队列串行的结构性成本（每晚一次 master 移动给全部在途 PR 加一轮），只有压缩在途重叠才能压掉。
2. **清偿评论竞态**：发生率 7/12 根（§3），代价 = 8 次 rerun（pr-gate 复跑实测 0.2–0.3min/次 + 排队等待 10–30min 墙钟/根；#510 双 rerun 含开式整改）。修法在册且已生效：push 落定 → **先等 pr-gate run 出现再贴覆盖清偿** → 或贴后 `gh run rerun --failed`（合法修复，L7323）。
3. **审查段是全链路最大不确定段**：在案 6 根审查段实测 20m47s–1h30m12s（中位 ≈30m），5 根回报无承载（流程缺陷：席回报未落 PR 评论即销席）；#514 的 BLOCK→整改→复审全环 = 05:09→06:12 ≈63m。
4. **fmerge 工具缺陷**：`gh pr update-branch` 对本仓无效（sync16 L7330），手动 fmerge 正确但每根 1–2 轮全套 CI；docs-only 棒本地 docs:probe 必跑（L7323）。
5. **#492 真红轮**（夜批）：5 红轮 ×13.8–21.9 分钟 = 总 6h34m 的主因，属 u7-0 重放仪式学习成本（EF-05/EF-06 教训已入册），与队列结构无关。
